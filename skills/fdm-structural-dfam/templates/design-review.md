# 结构设计审查

## 设计输入与假设
填写实际值、来源、未知项与假设，不省略关键工况。

## 载荷路径与失效模式
说明加载点、反力、偏心力矩、最弱截面、局部张开和连接风险。

## 打印朝向比较
分别记录方案 A、方案 B 的打印 Z 轴、关键局部应力与层面关系、支撑、孔与翘曲风险；给出最终选择依据。

## 已实施的几何与材料方案
记录尺寸、根部圆角、肋、壁、孔、五金、材料牌号和依据。

## 切片与装配
记录喷嘴、层高、线宽、壁数、填充、主辅材料、支撑、缝和配合试片结果。

## 证据与状态
CAD 导出：未执行 / 已执行（文件与版本）
网格检查：未执行 / 有问题 / 已筛查（结果文件）
切片预览：未执行 / 有问题 / 已检查（配置与截图）
力学计算：未执行 / 初步筛查 / 经核验（模型及假设）
实物测试：未执行 / 未通过 / 满足指定验收条件（记录）
审核：未完成 / 已完成（人员、日期和适用范围）

## 待验证项
列出未覆盖的疲劳、蠕变、温度、冲击、材料界面、预紧与寿命条件。
