# 来源与使用边界

本包是原创的设计工作流，不是视频逐字稿，也不宣称得到任何设备厂商背书。梁公式与载荷路径用于有条件的初步筛查，不构成材料承载认证。

以下为核对过的英文原始资料。机型资料可能随软硬件版本更新，实际使用时仍须核对当前配置。

1. Agent Skills specification： https://agentskills.io/specification
   用于 Skill 目录、元数据与按需读取文件的组织。
2. Bambu Lab X2D 官方发布说明： https://blog.bambulab.com/xcellence-made-simple-bambu-lab-presents-the-x2d/
   用于 X2D 设备类型与主辅喷嘴工作分工的概述，不将宣传语当成强度实测。
3. Bambu Lab 主辅挤出原理： https://blog.bambulab.com/two-extruders-one-purpose-what-is-x2d-direct-drive-extrusion-and-auxiliary-extrusion/
   用于区别主直驱与辅助送料路径，提示配置和材料分别核对。
4. Prusa 官方层高与外壁文档： https://help.prusa3d.com/article/layers-and-perimeters_1748
   用于说明层高、外壁与切片设置需要共同考虑；不能据此推导任意结构的承载数值。

一般性规则的具体应用必须引用项目使用的材料技术资料、试片与试验记录。ISO/ASTM 52910 在主文中仅作为通用设计指导的名称，不假定本文已覆盖其完整要求或构成标准符合性声明。
